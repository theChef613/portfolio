# Portfolio

## Project Overview
This is the personal portfolio website for **Yaakov Schefres**. It showcases his projects, experience, and contact information.

## Development & Maintenance
This website is actively maintained using an automated, AI-driven workflow:

### Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript
- **Hosting**: Nextcloud/Local Environment
- **AI Agent**: [Hermes Agent](https://hermes-agent.nousresearch.com/)
- **Inference Engine**: [LM Studio](https://lmstudio.ai/)
- **Model**: [Gemma 4](https://ai.google.dev/gemma)

### AI Workflow
The repository is maintained by an intelligent coding agent (Hermes) running on a local instance of LM Studio. This setup allows for:
- **Automated Code Updates**: Efficiently patching HTML, CSS, and JS files.
- **Context-Aware Refactoring**: Ensuring consistency across the entire codebase (e.g., updating email addresses in all locations simultaneously).
- **Documentation & Maintenance**: Automating routine tasks like updating `.gitignore` and refining site content.

By leveraging Gemma 4 through Hermes Agent, the portfolio can be updated and managed with high precision and minimal manual intervention.
